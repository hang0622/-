# STM32F103C8T6 定时控制电机 + OLED 时钟显示

每天到设定时刻启动电机运行指定秒数后自动停止；0.96 寸 **4 针 I2C OLED** 实时显示当前日期、时间、下次运行时刻与电机状态。

## 功能

- DS1302 实时时钟
- 每 24 小时在设定时刻（默认每天 **08:00**）启动电机，默认运行 **3 秒**
- 电机转速由 PWM 调节（默认 30% 占空比，可调）
- 0.96 寸 OLED（软件 I2C）实时显示：
  - 当前日期与星期（如 `2026-08-31 Mon`）
  - 当前时间（大字号，时:分:秒）
  - 下次运行时刻（如 `Next:08:00`，改分钟模式时显示 `*M`）
  - 电机状态（`Motor: RUN!` / `Motor: IDLE`）
- **Key2：立即手动试跑 3 秒**（时长与定时启动独立可调）
- Key1：短按改触发小时；长按约 1.5 秒切换「改分钟」模式，再用 Key2 加分钟
- 电机运行时长用 **TIM3 硬件毫秒计时**，不受主循环负载影响，秒数精确
- 内置 OLED 诊断模式（可单独验证屏幕/接线/供电）

## 接线

### DS1302

| DS1302 | STM32 |
|--------|-------|
| VCC | 3.3V |
| GND | GND |
| CE/RST | PB12 |
| I/O | PB13 |
| SCLK | PB14 |

### TB6612 + 电机

| TB6612 | 接法 |
|--------|------|
| PWMA | PA2 |
| AIN1 | PA4 |
| AIN2 | PA5 |
| STBY | **PA3**（程序控制；也可直接接 3.3V） |
| VCC | 3.3V |
| GND | 与 MCU **共地** |
| VM | **外接 5V**（不要接 MCU 的 3.3V） |
| AO1 / AO2 | 电机两端 |

> 上电会自动转 3 秒；按 Key2 再转 3 秒。灯常亮期间电机应转。

### OLED（4 针 I2C）

4 针 OLED 模块（SSD1306）引脚顺序通常为 `GND VCC SCL SDA`，**模块背面 BS0/BS1 焊盘需焊在 I2C 模式**。

| OLED | STM32 |
|------|-------|
| GND | GND |
| VCC | **3.3V**（不要接 5V） |
| SCL | **PB8** |
| SDA | **PB9** |

> 软件 I2C 驱动，从机地址 **0x78**（7 位地址 0x3C）。SCL/SDA 为开漏输出，模块板载上拉电阻。PB8/PB9 与 DS1302(PB12/13/14)、电机(PA2/3/4/5)、按键(PB1/PB11) 均无冲突，无需关 JTAG。
>
> ⚠️ 本表与代码一致（`OLED.c` / `OLED.h` / `main.c` 注释均为同一组引脚），请以此为准接线。

### 按键

| 按键 | STM32 | 功能 |
|------|-------|------|
| Key1 | PB1 → GND | 短按：触发小时 +1；长按 1.5s：切换改分钟模式 |
| Key2 | PB11 → GND | 运行模式：试跑 3 秒；改分钟模式：分钟 +1 |

## 使用步骤（Keil5）

### 第 1 步：首次烧录前设置时间

打开 `定时控制电机\Project.uvprojx`，编辑 `User\main.c` 顶部：

```c
#define NEED_SET_TIME			1    /* 需要写入时间时设为 1 */
#define SET_YEAR				2026
#define SET_MONTH				8
#define SET_DAY					31
#define SET_HOUR				23
#define SET_MINUTE				9
#define SET_SECOND				0
#define SET_WEEK				1
```

把 `SET_YEAR / SET_MONTH / SET_DAY / SET_HOUR / SET_MINUTE / SET_SECOND / SET_WEEK` 改成**当前真实时间**（星期 1~7 对应周一~周日）。

### 第 2 步：编译并下载

1. 点击 **Rebuild**，确认输出 `0 Error(s)`（不要有红色报错）
2. 点击 **Load**（Flash → Download）烧录到板子
3. 按板子 Reset 复位

### 第 3 步：改回正常运行

把 `NEED_SET_TIME` 改回 **`0`**，再编译下载一次（避免每次上电都重置时间）。

### 第 4 步：验证

1. 上电后 OLED 应显示当前日期时间；第 2 行 `Next:08:00` 为下次自动启动时刻
2. 按 **Key2**：灯快闪后常亮约 3 秒，电机应转动（30% 转速，`MOTOR_SPEED` 可调）
3. 改触发时间：短按 Key1 加小时；长按 Key1 进入改分钟模式，再按 Key2 加分钟

## 可调参数（`main.c`）

| 参数 | 含义 |
|------|------|
| `RUN_SECONDS` | 定时自动启动的运行秒数（默认 3） |
| `KEY2_RUN_SECONDS` | 按 Key2 手动试跑秒数（默认 3，与定时时长独立可调） |
| `MOTOR_SPEED` | 电机转速 1~100（占空比 %，默认 40；数值越小越慢） |
| `RunHour` / `RunMinute` | 默认定时时刻（默认 08:00） |
| `OLED_TEST_ONLY` | 1=OLED 自检模式；0=正常运行 |

> 转速提示：`MOTOR_SPEED` 低于约 10 时电机可能因 PWM 死区启动不起来或抖动；若需低速平稳启动，可再加"软启动"逻辑。

## OLED 诊断模式（排障专用）

若 OLED 不显示，可把 `main.c` 中：

```c
#define OLED_TEST_ONLY			1
```

烧录后板载灯先快闪 3 下，随后 OLED **全亮 2 秒 → 全灭 2 秒 → 再亮**循环（每次切换板载灯也跟随亮/灭）。按现象判断：

| 板载灯 | OLED | 结论 |
|--------|------|------|
| 快闪3下后循环亮/灭 | 屏幕跟随全亮/全灭 | 屏幕和接线正常，问题在显示逻辑 |
| 快闪3下后循环亮/灭 | 屏幕永远全黑 | 屏没收到数据 → 查 VCC/GND/SCL/SDA 接线、供电、模块 I2C 模式焊盘 |
| 连快闪3下都没有 | 全黑 | 固件未烧成功 → 重编译确认 0 Error 再下载 |

> 调试完成后记得改回 `OLED_TEST_ONLY = 0`。

## 板载灯（PC13）含义

| 现象 | 含义 |
|------|------|
| 上电快闪 5 下 | 程序启动 |
| 上电后再快闪 8 下 | 已写入 DS1302 时间（NEED_SET_TIME=1 时） |
| 约 1 秒闪一次 | 空闲等待 |
| 常亮约 3 秒 | 电机正在运行 |
| 快闪 4 下后常亮 | 按 Key2 开始试跑 |
| 快闪 6 下 | 进入改分钟模式 |
| 快闪 3 下 | 退出改分钟模式（回到改小时） |

## 常见问题排查

### 电机不转
1. **STBY 是否接到 3.3V**
2. **VM 是否外接 5V，且与单片机 GND 相连**
3. PWMA→PA2，AIN1→PA4，AIN2→PA5
4. `MOTOR_SPEED` 是否设得太低（低于约 10 可能启动不起来），可临时调大到 60 验证

### 电机运行时长不准
运行时长由 **TIM3 硬件毫秒计时** 控制（`Tick_Init()` + `stm32f10x_it.c` 的 `TIM3_IRQHandler`），与主循环负载无关，正常误差在 1ms 级。若实测仍有偏差，可微调 `RUN_SECONDS` / `KEY2_RUN_SECONDS` 的补偿值。

### OLED 不亮
1. **模块背面 BS0/BS1 焊盘是否焊在 I2C 模式**（4 针屏必须是 I2C，不能是 SPI 模式）
2. **VCC 接 3.3V**，GND 与单片机共地
3. SCL→PB8、SDA→PB9（开漏输出，模块板载上拉；若模块无上拉，可在 SCL/SDA 各加 4.7k 上拉到 3.3V）
4. 用 `OLED_TEST_ONLY = 1` 诊断模式判断是屏还是接线问题
5. 若确认接线无误仍黑屏，优先怀疑屏幕本身（可换屏验证）
